# Module Tests

This directory serves as the default storage location for test results generated by the evaluation scripts.

## Test Outputs

The results are typically saved in CSV format with the following naming convention:
`[model_name]_[yy-mm-dd-hh-mm-ss].csv`

### Data Format

Each CSV file contains the following columns:
- **`cve_id`**: The unique identifier for the vulnerability.
- **`predicted`**: The CWE labels predicted by the model.
- **`groundtruth`**: The actual CWE labels as reported by the NVD.
